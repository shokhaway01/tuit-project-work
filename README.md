## 📌 Description

**Shokhaway INC** — это платформа для обучения, которая объединяет:

* 📚 курсы
* 🎥 видеоуроки
* 🧠 тесты

Проект разработан как MVP для стартап-выставки в TUIT.

---

## ⚙️ Features

* 📚 Тематические курсы
* 🎥 Видеоуроки
* 🧠 Тестирование по темам
* ⚡ Быстрый интерфейс (SPA)
* 🔄 Навигация между разделами
